# Smart Campus Navigator 🗺️

An interactive, responsive campus map system built for Dr. B.R. Ambedkar Polytechnic College.

## Core Features
* **Interactive Map:** Pan, zoom, and explore campus locations.
* **Live Navigation:** Real-time GPS tracking and pathfinding to destinations.
* **Custom Routing Engine:** Custom Dijkstra implementation for accurate indoor and outdoor routing.
* **Mobile Friendly:** Bottom-sheet UI for a smooth mobile experience.

## Tech Stack
* HTML, CSS, Vanilla JavaScript
* Leaflet.js (for map rendering)
